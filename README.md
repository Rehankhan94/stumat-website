# STUMAT project website

Public information site for **STUMAT**: “Development of Smart PHBV films with microencapsulated spirulina as TUnable food contact MATerials.”

STUMAT is a Horizon Europe Marie Skłodowska-Curie Actions Postdoctoral Fellowship (grant agreement **101203141**, 4 May 2026 to 3 May 2028). AgroParisTech Innovation coordinates the project, with INRAE as a partner organisation. [Official CORDIS fact sheet](https://cordis.europa.eu/project/id/101203141).

## Pages

- `index.html`: introduction and project story
- `research.html`: work packages and original explanatory diagram
- `engagement.html`: proposed timeline, dissemination, communication and outreach
- `about.html`: researcher and project environment

The project roadmap and engagement activities describe **plans from the original proposal**, not completed results or confirmed public events. This static site is built with HTML, CSS and a small amount of JavaScript; no build step is needed. It supports keyboard navigation, mobile layouts and reduced-motion preferences.

## Publishing

In the repository's **Settings → Pages**, publish the `main` branch from `/(root)`. The website then appears at `https://rehankhan94.github.io/stumat-website/`.
